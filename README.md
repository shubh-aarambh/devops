## Assignment Overview & Scope

1. **Linux Fundamentals (Session 1 & 2):** Inodes, soft vs hard links, `adduser` vs `useradd`, `journalctl` logging, and Linux cheat sheet verification.
2. **Shell Scripting (Session 3):** Automated system profiling script capturing date, hostname, disk usage (`df`), processes (`ps`), and user prompt handling.
3. **Networking Fundamentals (Session 4):** 13 core networking commands (`ip a`, `ping`, `nslookup`, `curl`, `ss`, routing, `/etc/hosts`).
4. **Git & GitHub (Session 5):** `git commit -a -m` tracking dynamics, branching, and commit cherry-picking with git logs.
5. **Docker Fundamentals (Session 6):** 6 microservices containerized across Node.js, Python, Java, Apache, React, and Nginx.
6. **Docker Images (Session 7):** Multi-stage build optimization reducing image footprint from 1.6GB to 194MB, running on port 8080.
7. **Docker Networking (Session 8):** Isolated user bridge networks, multi-homed backend routing, host networking, bind mounts, and overlay networking.
8. **Kubernetes Fundamentals (Session 9):** Minikube cluster lifecycle, control-plane vs worker architecture, and core object taxonomy.
9. **Kubernetes Pods, ReplicaSets & Deployments (Session 10):** Pod lifecycle state transitions and rollout strategies: RollingUpdate, Blue-Green, Canary, Recreate.
10. **Kubernetes Networking & Services (Session 11):** ClusterIP, NodePort, LoadBalancer, ExternalName, Headless Services, and CoreDNS FQDN resolution.
11. **Kubernetes Ingress, ConfigMaps & Secrets (Session 12):** External traffic routing with NGINX Ingress, decoupled configuration, and Base64 secrets.
12. **Kubernetes Storage, HPA & Probes (Session 13):** Dynamic volume provisioning (PV/PVC), Horizontal Pod Autoscaling under simulated CPU stress, and liveness/readiness probes.
13. **Kubernetes Troubleshooting (Session 14):** Systematic triage drills for CrashLoopBackOff, ImagePullBackOff, Pending pods, and Service endpoint selector mismatches.
14. **Helm (Session 15):** Package management, templating, custom values injection, release revisions, and automated rollbacks.
15. **CI/CD & GitHub Actions (Session 16):** Multi-job pipeline containing build, unit testing, Docker image packaging, and deployment stages.
16. **Complete CI/CD & DevSecOps (Session 17):** Full DevSecOps pipeline with SAST (Bandit), SCA (pip-audit), secret scanning (Gitleaks), and container vulnerability scanning (Trivy).
17. **Terraform & Infrastructure as Code (Session 18):** AWS S3 provisioning workflow with `init`, `plan`, `apply`, drift detection, and `destroy`.
18. **Cloud & Terraform in Action (Session 19):** End-to-end VPC, public/private subnets, Security Groups, IAM roles, EC2, and S3 architecture.
19. **Monitoring, Observability & GitOps (Session 20):** Prometheus metrics, Grafana dashboards, alerting triggers, OpenTelemetry traces, and Argo CD GitOps reconciliation.
20. **Final DevOps Project & Troubleshooting (Session 21):** 3-tier multi-container architecture (Frontend, Backend, PostgreSQL), Docker Compose orchestration, health check gates, REST API testing, and troubleshooting.
